# Project History

- **V1:** Initial AYRA static creative portfolio recreation with major visual deviations.
- **V2:** Higher-resolution portrait, new project artwork, revised layout and process interactions.
- **V3:** Shutter-style services, cursor-lighting changes, scroll-controlled project cards.
- **V4:** Improved local pointer lighting, additional responsive fixes and 3D reactions.
- **V5:** Rebuilt section order, introduced custom spring cursor and eye direction layers, measured gallery movement and responsive behavior.
- **V6 (current committed baseline):** Further fidelity CSS/JS, bento and responsive refinements, fresh Chromium QA across seven viewport sizes, documentation and source packaging.

Earlier experimental versions and third-party reference video are **not** distributed in this repository because V6 is the maintained baseline. The prior iteration files remain part of the user's ChatGPT artifact history, not Git history on this new repository.

**Not complete:** Direct source-level identity with the external template, original facial tracking, exact imagery/fonts, frame-matched color and motion timing. See `docs/QA_REPORT.md`.
